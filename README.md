# RepoLens Sandbox

This is a sandbox repository for team onboarding, Git practice, and research notes.

## Team Workflow
1. Never push directly to `main`.
2. Create a personal branch: `git checkout -b <your-name>/<task-name>`.
3. Add your notes or code in the `notes/` directory.
4. Commit your changes: `git commit -m "docs: add research notes"`.
5. Push to GitHub: `git push -u origin <your-branch-name>`.
6. Open a Pull Request (PR) for review!
